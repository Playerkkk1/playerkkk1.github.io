# 模板示例归档

这里保留从站点发布集合中移出的 Firefly 示例，供编写文章或配置功能时参考，不参与 Astro 内容集合、搜索、归档、RSS 或项目列表生成。

- `posts/`：14 篇模板文章（包含草稿与使用指南）。
- `projects/`：2 个模板示例项目。
- `dynamic/`：4 条测试动态。
- `config/*.ts.txt`：书签、友链、相册和音乐的原始示例配置；保存为 `.txt`，避免被 TypeScript 当作项目代码检查。

本站的 Redis 文章和个人介绍保持原样。页面、导航和功能入口继续保留，尚未填写的数据以空状态显示。

原示例配图和音乐素材未删除。若需复用这些演示，请把文档移回 `src/content/` 下的原路径，以恢复相对图片引用。`posts/guide/` 对应 `src/content/posts/guide/`，其他目录同理。

本次清理不删除 Firefly / Astro 的版权和开源许可说明。
