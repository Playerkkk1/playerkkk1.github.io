## 一、普通树的遍历

普通树与二叉树不同，一个节点可以拥有多个孩子，因此遍历规则也有所区别。

### 1. 先根遍历

先访问根节点，再按照从左到右的顺序依次遍历根节点的每棵子树。

例如：

```
        A
      / | \
     B  C  D
       / \
      E   F
```

先根遍历：

`A → B → C → E → F → D`

### 2. 后根遍历

先按照从左到右的顺序遍历所有子树，最后访问根节点。

上面这棵树的后根遍历：

`B → E → F → C → D → A`

注意：后根遍历不是简单地将先根遍历的结果倒过来。

## 二、树转换为二叉树后的遍历对应关系

树转换为二叉树使用左孩子右兄弟表示法：

- 左指针：指向第一个孩子。
- 右指针：指向下一个兄弟。

转换后：

**树的先根遍历 = 对应二叉树的先序遍历。**

**树的后根遍历 = 对应二叉树的中序遍历。**

### 1. 先根遍历与先序遍历

普通树先根遍历：

`A → B → C → E → F → D`

转换后的二叉树进行先序遍历：

`A → B → C → E → F → D`

两者结果一致。

### 2. 后根遍历与中序遍历

普通树后根遍历：

`B → E → F → C → D → A`

转换后的二叉树进行中序遍历：

`B → E → F → C → D → A`

两者结果也一致。

## 三、森林的遍历

森林由多棵互不相交的树组成。

森林遍历时，按照从左到右的顺序依次处理各棵树。

### 1. 森林的先序遍历

先序遍历第一棵树，再依次遍历后面的树。

### 2. 森林的中序遍历

依次对森林中的每棵树进行后根遍历，再将结果连接起来。

## 四、森林转换为二叉树后的遍历对应关系

森林转换为二叉树时：

1. 每棵树内部使用左孩子右兄弟表示法。
2. 各棵树的根节点通过右指针连接。
3. 第一棵树的根节点作为转换后二叉树的根节点。

因此：

**森林的先序遍历 = 对应二叉树的先序遍历。**

**森林的中序遍历 = 对应二叉树的中序遍历。**

### 实例练习

已知森林：

```
       A               E
      / \             / \
     B   C           F   G
         |
         D
```

第一棵树的结构：

- A 有两个孩子 B、C。
- C 有一个孩子 D。

第二棵树的结构：

- E 有两个孩子 F、G。

#### 森林先序遍历

第一棵树：A、B、C、D。

第二棵树：E、F、G。

最终：

`A → B → C → D → E → F → G`

#### 森林中序遍历

第一棵树进行后根遍历：

`B → D → C → A`

第二棵树进行后根遍历：

`F → G → E`

最终：

`B → D → C → A → F → G → E`

转换为二叉树后，分别进行先序和中序遍历，也会得到相同的结果。

## 五、期末考试重点总结


| 原结构遍历方式 | 转换后二叉树的遍历方式 |
| ------- | ----------- |
| 树的先根遍历 | 先序遍历 |
| 树的后根遍历 | 中序遍历 |
| 森林的先序遍历 | 先序遍历 |
| 森林的中序遍历 | 中序遍历 |


记忆口诀：

```
树的先根 → 二叉树先序
树的后根 → 二叉树中序

森林先序 → 二叉树先序
森林中序 → 二叉树中序
```

注意：这里的森林中序遍历是指依次对每棵树进行后根遍历，不要与普通二叉树的后序遍历混淆。

## 六、易错点

1. 普通树的先根遍历与二叉树先序遍历对应。
2. 普通树的后根遍历与二叉树中序遍历对应。
3. 森林的先序遍历要依次处理每棵树。
4. 森林的中序遍历要依次处理每棵树的后根遍历。
5. 不要把二叉树的后序遍历误认为树的后根遍历。

## 七、本篇小结

本节最重要的是理解树、森林与二叉树之间的遍历对应关系。

通过左孩子右兄弟表示法，普通树和森林可以转换为二叉树，并且保留特定的遍历结果。
