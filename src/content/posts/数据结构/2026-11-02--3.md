## 1. 题型介绍

以前的题是**给出树，求遍历序列**；现在反过来：**给出先序与中序序列，还原二叉树**。

在**节点值互不相同**的前提下，先序与中序序列可以唯一确定一棵二叉树。

核心口诀：

> **先序找根 → 中序分左右 → 对左右子树重复操作。**

## 2. 基础例题

已知：

- 先序：`A B D C`
- 中序：`D B A C`

### 第一步：先序找根

先序第一个节点是 A，所以根为 A。

### 第二步：中序分左右

```text
D B | A | C
左    根   右
```

因此 A 的左子树包含 B、D；右子树只有 C。

### 第三步：对子树重复

左子树的先序为 `B D`，中序为 `D B`。

- 先序第一个节点 B 是左子树根。
- 中序 `D | B`，D 在 B 左边，所以 D 是 B 的左孩子。

最终：

```text
      A
     / \
    B   C
   /
  D
```

验证：先序 A B D C；中序 D B A C，均与题目一致。

## 3. 进阶例题：期末计算题

已知：

- **先序：** `A B D G E C F H`
- **中序：** `D G B E A C H F`

### ① 找整棵树的根

先序首节点 A 是根。

中序划分：

```text
D G B E | A | C H F
  左      根    右
```

左右子树序列：


| 子树 | 先序 | 中序 |
| --- | ------- | ------- |
| 左 | B D G E | D G B E |
| 右 | C F H | C H F |


### ② 还原左子树

左子树先序 `B D G E`，首节点 B 是根。

左子树中序：`D G | B | E`。

- B 的左子树包含 D、G；右孩子是 E。
- 对 D、G 继续分析：先序 `D G`，中序 `D G`。
- D 是根；中序里 G 在 D 右边，因此 **G 是 D 的右孩子**。

```text
      B
     / \
    D   E
     \
      G
```

### ③ 还原右子树

右子树先序 `C F H`，中序 `C H F`。

- 先序首节点 C 是根。
- 中序 `C | H F`，说明 C 没有左子树，右子树包含 H、F。
- 对右子树：先序 `F H`，中序 `H F`。
- F 是根；H 位于 F 左边，所以 **H 是 F 的左孩子**。

```text
    C
     \
      F
     /
    H
```

### ④ 拼成完整二叉树

```text
         A
        / \
       B   C
      / \   \
     D   E   F
      \     /
       G   H
```

### ⑤ 写出后序遍历

后序规则：**左 → 右 → 根**。

- A 的左子树后序：`G D E B`。
- A 的右子树后序：`H F C`。
- 最后访问根 A。

**最终后序：`G D E B H F C A`。**

## 4. 常见错误

1. **找到了整棵树的根，却不知道怎么继续**：把每个子树单独拿出来，再执行“先序找根、中序分左右”。
2. **根据先序相邻就判断左右关系**：相邻不代表一定是左右孩子，要结合中序分界。
3. **子树范围切错**：先根据中序确定左右子树各有几个节点，再从先序中划分对应长度。
4. **还原后不验证**：画好树后，重新求先序、中序，必须与题目完全一致。

## 5. 复习速记

```text
先序：第一个是根
中序：根左边属于左子树，根右边属于右子树
对子树：重复相同过程，直到只剩一个节点
检查：重新遍历验证
```
