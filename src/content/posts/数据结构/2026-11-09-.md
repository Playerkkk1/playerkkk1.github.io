## 一、二叉树的存储结构

二叉树常见的存储方式有两种：

1. 顺序存储
2. 链式存储

### 1. 顺序存储

顺序存储使用数组保存二叉树节点，通常按照层序遍历的顺序依次存放。

对于完全二叉树，采用从 1 开始的节点编号：

- 左孩子编号：`2i`
- 右孩子编号：`2i + 1`
- 双亲节点编号：`⌊i / 2⌋`

例如：

```
        A(1)
       /    \
    B(2)    C(3)
    / \     / \
 D(4) E(5) F(6) G(7)
```

节点 B 的编号为 2：

- 左孩子 D：2 × 2 = 4
- 右孩子 E：2 × 2 + 1 = 5
- 双亲 A：⌊2 / 2⌋ = 1

**特点：**

完全二叉树使用顺序存储比较节省空间，而不规则二叉树可能产生大量空位置。

### 2. 链式存储

链式存储使用节点和指针保存二叉树结构。

每个节点通常包含三个部分：

`lchild | data | rchild`

- lchild：左孩子指针
- data：数据域
- rchild：右孩子指针

如果节点没有对应的孩子，指针域为 null。

链式存储适用于各种形状的二叉树，不需要像顺序存储那样保留大量空位置。

## 二、二叉链表的空指针域计算

假设一棵二叉树有 n 个节点。

每个节点有两个孩子指针，因此：

总指针域数 = `2n`

一棵非空二叉树有 n 个节点，则有 n - 1 条边。

每条边对应一个非空孩子指针，因此：

非空指针域数 = `n - 1`

所以：

```
空指针域数
= 总指针域数 - 非空指针域数
= 2n - (n - 1)
= n + 1
```

最终公式：

**空指针域数 = n + 1**

### 通过节点的度计算

设：

- n₀：度为 0 的节点数，即叶子节点数。
- n₁：度为 1 的节点数。
- n₂：度为 2 的节点数。

不同节点的空指针域数量：


| 节点类型 | 空指针域数量 |
| ---- | ------ |
| 度为 0 | 2 |
| 度为 1 | 1 |
| 度为 2 | 0 |


因此：

`空指针域数 = 2n₀ + n₁`

又因为：

`n₀ = n₂ + 1`

所以也可以得到：

`空指针域数 = n + 1`

## 三、线索二叉树

### 1. 为什么需要线索二叉树？

普通二叉链表中存在 n + 1 个空指针域。

这些空指针域原本没有保存孩子节点的信息，因此可以利用它们保存节点在遍历序列中的前驱和后继。

这种利用空指针域保存遍历关系的二叉树称为线索二叉树。

### 2. 前驱与后继

前驱和后继是相对于某一种遍历方式而言的。

例如：

```
        A
       / \
      B   C
     / \
    D   E
```

中序遍历：

`D → B → E → A → C`

以 E 为例：

- 中序前驱：B
- 中序后继：A

注意：前驱和后继不一定是父节点或孩子节点，而是遍历序列中相邻的节点。

### 3. ltag 和 rtag

线索二叉树通常在节点中增加两个标志位：

`ltag | lchild | data | rchild | rtag`

采用常见约定：


| 标志位 | 0 | 1 |
| ---- | -------- | ------- |
| ltag | 左指针指向左孩子 | 左指针指向前驱 |
| rtag | 右指针指向右孩子 | 右指针指向后继 |


注意：只有原本为空的指针域才能建立线索，不能覆盖原来的孩子指针。

## 四、中序线索化

以中序遍历为例：

```
        A
       / \
      B   C
     / \
    D   E
```

中序遍历序列：

`D → B → E → A → C`

对应前驱和后继：


| 节点 | 中序前驱 | 中序后继 |
| --- | ---- | ---- |
| D | 无 | B |
| B | D | E |
| E | B | A |
| A | E | C |
| C | A | 无 |


判断指针时，必须先检查原二叉树结构。

例如：

- B 有左孩子 D、右孩子 E，因此两个标志位都是 0。
- E 没有左右孩子，因此两个标志位都是 1。
- D 没有左孩子，可以建立前驱线索；没有右孩子，可以建立后继线索。

不带头节点的线索二叉树中，第一个节点没有前驱，最后一个节点没有后继，对应线索指针为 null。

## 五、中序线索二叉树的遍历

普通二叉树进行中序遍历时，通常需要递归或者辅助栈。

中序线索二叉树可以利用线索直接寻找后继，不需要递归和辅助栈。

### 1. 寻找中序后继的两种情况

**情况一：rtag = 1**

说明右指针是线索，可以直接沿右指针找到中序后继。

**情况二：rtag = 0**

说明右指针指向真正的右孩子。

此时：

1. 先进入右子树。
2. 再沿左孩子指针不断向左。
3. 找到右子树中最左边的节点。

该节点就是当前节点的中序后继。

### 2. 为什么要寻找右子树最左边的节点？

中序遍历遵循：

`左 → 根 → 右`

当当前节点已经访问完毕，需要进入右子树时，右子树内部仍然需要遵循左根右的顺序。

因此不能直接访问右孩子，而应该先找到右子树中最左边的节点。

例如：

```
        A
         \
          B
         /
        C
       /
      D
```

中序遍历：

`A → D → C → B`

A 的右孩子是 B，但 A 的中序后继是 D。

因为进入 B 的右子树后，还需要依次向左寻找，直到 D。

### 3. 中序遍历的完整思路

1. 从根节点出发，沿左孩子指针寻找第一个节点。
2. 访问当前节点。
3. 根据 rtag 判断如何寻找后继。
4. 重复访问，直到没有后继。

## 六、Java 中寻找中序后继的核心逻辑

```
ThreadNode next(ThreadNode p) {
    if (p == null) {
        return null;
    }

    // 右指针是线索，直接返回后继
    if (p.rtag == 1) {
        return p.right;
    }

    // 右指针是孩子，进入右子树
    p = p.right;

    // 寻找右子树中最左边的节点
    while (p != null && p.ltag == 0) {
        p = p.left;
    }

    return p;
}
```

这里的核心是区分孩子指针与线索指针，避免把前驱或后继误认为真正的孩子。
