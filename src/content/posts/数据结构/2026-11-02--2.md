> 摘要：通过不规则二叉树理解先序、中序、后序和层序遍历，并总结容易混淆的访问顺序。

## 1. 遍历的含义

遍历就是按照某种规则，**每个节点恰好访问一次**。

前三种属于深度优先遍历（DFS）的常见形式；层序遍历属于广度优先遍历（BFS）。

## 2. 四种遍历规则


| 遍历方式 | 访问顺序 | 记忆方法 |
| ---- | ----------- | ---- |
| 先序 | 根 → 左 → 右 | 根最先 |
| 中序 | 左 → 根 → 右 | 根在中间 |
| 后序 | 左 → 右 → 根 | 根最后 |
| 层序 | 自上而下、每层从左到右 | 按层访问 |


注意：这里的“左”“右”是指**整棵左子树、整棵右子树**，不只是左右两个孩子。

## 3. 完整例题

```text
        A
       / \
      B   C
     / \   \
    D   E   F
       / \ /
      G  H I
```

父子关系：A 的左右孩子是 B、C；B 的左右孩子是 D、E；E 的左右孩子是 G、H；C 只有右孩子 F；F 只有左孩子 I。



### 先序：根 → 左 → 右

先访问 A，再遍历 B 的整棵子树，最后遍历 C 的整棵子树。

**A B D E G H C F I**

### 中序：左 → 根 → 右

B 的子树：D B G E H；然后访问 A；C 的子树：C I F。

**D B G E H A C I F**

### 后序：左 → 右 → 根

B 的子树：D G H E B；C 的子树：I F C；最后访问 A。

**D G H E B I F C A**

### 层序：逐层从左到右

**A B C D E F G H I**

层序遍历通常使用**队列**：先进入队列的节点先被处理（FIFO）。

## 4. 单分支结构的关键练习

```text
    A
     \
      B
     /
    C
```

- 先序：A B C。
- 中序：A C B。
- 后序：C B A。
- 层序：A B C。

中序遍历时，A 没有左子树，所以先访问 A；随后进入 B 的子树，先访问 C 再访问 B。

## 5. 在练习中暴露的易错点

1. **单分支左右混淆**：只有一个孩子时，必须看清它位于左边还是右边。
2. **漏节点或重复节点**：遍历结果长度必须等于原树节点数，每个节点只出现一次。
3. **误把左右孩子当成左右子树**：要完整处理一棵子树后才能返回。

## 6. 考试检查方法

- 先序结果第一个节点一定是整棵树的根。
- 后序结果最后一个节点一定是整棵树的根。
- 中序中根的位置不固定，要由左右子树大小决定。
- 层序要逐层核对，避免漏掉最底层节点。
- 最后核对：**节点数一致、没有重复、没有遗漏**。

## 7. 自测

```text
      A
     / \
    B   C
     \
      D
```

分别写出先序、中序、后序、层序遍历。

展开参考答案

- 先序：A B D C
- 中序：B D A C
- 后序：D B C A
- 层序：A B C D
