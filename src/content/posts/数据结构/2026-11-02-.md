## **1. 树是什么？**

树是一种**非线性数据结构**，由节点和连接节点的边构成。除根节点外，每个节点恰好有一个父节点；树中不存在环。

```
         A
        / \
       B   C
      / \
     D   E
```

- **根节点**：A，没有父节点。
- **父节点 / 孩子节点**：A 是 B、C 的父节点；B、C 是 A 的孩子。
- **兄弟节点**：B 和 C 具有相同父节点。
- **叶子节点**：没有孩子的节点，如 C、D、E。
- **节点的度**：节点拥有的孩子数量。例如 A 的度为 2，B 的度为 2，C 的度为 0。
- **树的度**：整棵树中节点度的最大值，此例为 2。

## **2. 层次与高度**

约定**根节点位于第 1 层**，其孩子位于第 2 层，以此类推。

```
 第1层          A
               / \
 第2层        B   C
             / \
 第3层      D   E
```

按“层数”定义的树高为 3。注意：有些教材把高度按**边数**计算，考试时应以课程约定为准。

## **3. 二叉树的定义**

二叉树是每个节点**最多只有两个孩子**的树，并且明确区分**左子树**和**右子树**。

- 可以没有孩子。
- 可以只有左孩子，或只有右孩子。
- 左右子树不能随意交换；交换后通常视为不同的二叉树。

```
     A          A
    /            \
   B              B
```

上面两棵二叉树不同：左边 B 是左孩子，右边 B 是右孩子。

## **4. 常见易错点**

1. **二叉树不要求每个节点都有两个孩子**，而是最多两个。
2. **叶子节点的度为 0**，不是 1。
3. **节点的度与树的度不同**：一个是单个节点的孩子数，一个是全树的最大节点度。
4. 画树时要保留左右位置，尤其是只有一个孩子的情况。​

## **本篇小结**

**二叉树 = 每个节点最多两个孩子 + 左右子树有区别。**
