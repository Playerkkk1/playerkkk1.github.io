# 01｜计算机网络概述

## 一、计算机网络的基本概念

计算机网络是将分布在不同地理位置、具有独立功能的计算机系统，通过通信设备和通信线路连接起来，并由网络软件实现资源共享和信息传递的系统。

计算机网络的主要功能：

1. 数据通信：实现不同设备之间的信息传递。
2. 资源共享：共享硬件、软件和数据资源。
3. 分布式处理：将任务分配给不同计算机完成。
4. 提高可靠性：通过多台设备协同工作提高系统可靠性。

## 二、互联网的组成

互联网从工作方式上可以划分为两个部分：

### 1. 边缘部分

由连接在互联网中的所有主机组成。

主要负责用户的信息处理和应用。

例如：

- 个人电脑
- 手机
- Web 服务器
- 数据库服务器

边缘部分主要通过两种方式进行通信：

- 客户-服务器方式（C/S）
- 对等方式（P2P）

### 2. 核心部分

由大量网络和连接这些网络的路由器组成。

核心部分主要负责数据的转发与传输。

其中，路由器是核心网络的重要设备，负责根据目的地址选择转发路径。

## 三、计算机网络的分类

### 1. 按照覆盖范围分类


| 类型 | 英文 | 特点 |
| ----- | --- | ------------- |
| 个人区域网 | PAN | 覆盖个人周围的小范围 |
| 局域网 | LAN | 覆盖学校、办公室、建筑物等 |
| 城域网 | MAN | 覆盖城市范围 |
| 广域网 | WAN | 覆盖较大地理区域 |


### 2. 按照使用者分类

- 公用网：面向公众开放使用。
- 专用网：由特定组织或单位使用。

### 3. 按照网络拓扑分类

- 总线型
- 星型
- 环型
- 网状型

## 四、计算机网络的性能指标

### 1. 速率

指数据的传输速率，即单位时间内传输的数据量。

常用单位：

- bit/s（比特每秒）
- kbit/s
- Mbit/s
- Gbit/s

注意：

1 Byte = 8 bit

### 2. 带宽

在计算机网络中，带宽通常表示网络的最大数据传输能力。

常用单位：Hz 或 bit/s，具体取决于语境。

### 3. 吞吐量

表示单位时间内通过某个网络或接口的实际数据量。

吞吐量会受到网络带宽、网络负载等因素影响。

### 4. 时延

数据从网络一端传送到另一端所需要的时间。

主要包括：

- 发送时延：将数据发送到链路上所需时间。
- 传播时延：电磁波在链路中传播所需时间。
- 处理时延：设备处理数据所需时间。
- 排队时延：数据在设备缓存中等待处理所需时间。

发送时延计算：

发送时延 = 数据长度（bit）÷ 发送速率（bit/s）

传播时延计算：

传播时延 = 信道长度 ÷ 信号传播速率

总时延：

总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延

### 5. 时延带宽积

时延带宽积 = 带宽 × 传播时延

表示链路中可以容纳的比特数量。

### 6. 往返时间 RTT

RTT（Round-Trip Time）表示数据从发送端到接收端，再返回发送端所需要的时间。

常用于衡量网络通信的响应时间。

## 五、数据交换方式

计算机网络主要有三种交换方式：

### 1. 电路交换

在通信双方之间建立一条专用的通信路径。

主要特点：

- 建立连接。
- 通信过程中独占通信资源。
- 通信结束后释放连接。

优点：通信时延较小，实时性较好。

缺点：资源利用率较低。

### 2. 报文交换

以完整报文为单位进行存储转发。

每个交换节点接收完整报文后，再转发给下一个节点。

特点：

- 不需要预先建立专用连接。
- 每个节点需要暂存完整报文。
- 适合非实时通信。

### 3. 分组交换

将较长的数据划分为较小的数据块，即分组，再通过网络进行传输。

每个分组独立传输，经过路由器转发后到达目的地。

特点：

- 不需要建立专用通信线路。
- 采用存储转发方式。
- 网络资源利用率较高。
- 可能产生排队时延和分组丢失。

### 三种交换方式对比


| 比较项目 | 电路交换 | 报文交换 | 分组交换 |
| ----- | ----- | ------ | ------------- |
| 连接建立 | 需要 | 不需要 | 通常不需要预先建立专用线路 |
| 传输单位 | 连续比特流 | 完整报文 | 数据分组 |
| 存储转发 | 不采用 | 采用 | 采用 |
| 资源利用率 | 相对较低 | 较高 | 较高 |
| 典型特点 | 独占线路 | 整体存储转发 | 分组存储转发 |


## 六、计算机网络体系结构

网络体系结构是计算机网络各层及其协议的集合。

采用分层结构，可以将复杂的网络通信任务拆分为不同层次，每层完成相对独立的功能。

### 1. OSI 七层参考模型


| 层次 | 名称 | 主要功能 |
| --- | ----- | ------------ |
| 第7层 | 应用层 | 为应用程序提供网络服务 |
| 第6层 | 表示层 | 数据表示、转换、加密等 |
| 第5层 | 会话层 | 建立、管理和终止会话 |
| 第4层 | 运输层 | 端到端进程通信 |
| 第3层 | 网络层 | 路由选择、逻辑寻址 |
| 第2层 | 数据链路层 | 成帧、差错检测、链路传输 |
| 第1层 | 物理层 | 比特流传输 |


记忆顺序：

从下到上：

物理层 → 数据链路层 → 网络层 → 运输层 → 会话层 → 表示层 → 应用层。

### 2. TCP/IP 体系结构

TCP/IP 体系结构通常采用四层模型：


| 层次 | 主要协议 |
| ----- | --------------------------------- |
| 应用层 | HTTP、FTP、DNS、SMTP |
| 运输层 | TCP、UDP |
| 网际层 | IP、ICMP、ARP（教材传统 TCP/IP 体系讨论中常涉及） |
| 网络接口层 | 以太网、无线局域网等 |


注意：不同教材也会将网络接口层进一步划分为数据链路层和物理层，形成五层教学模型。

### 3. OSI 与 TCP/IP 对应关系


| OSI 七层 | TCP/IP 四层 |
| ------ | --------- |
| 应用层 | 应用层 |
| 表示层 | 应用层 |
| 会话层 | 应用层 |
| 运输层 | 运输层 |
| 网络层 | 网际层 |
| 数据链路层 | 网络接口层 |
| 物理层 | 网络接口层 |


### 4. 五层教学模型

学习和理解网络通信时，经常使用五层模型：

1. 应用层
2. 运输层
3. 网络层
4. 数据链路层
5. 物理层

它将 TCP/IP 的网络接口层拆成物理层和数据链路层，便于理解数据传输过程。

## 七、数据封装与解封装

发送数据时，数据会从应用层逐层向下传递，每一层都会添加相应的控制信息。

这个过程称为数据封装。

接收端则从底层逐层向上处理，去除对应的控制信息，这个过程称为解封装。

各层常见数据单位：


| 层次 | 数据单位 |
| ----- | ------------------- |
| 应用层 | 报文 |
| 运输层 | 报文段（TCP）或用户数据报（UDP） |
| 网络层 | IP 数据报 |
| 数据链路层 | 帧 |
| 物理层 | 比特 |


## 八、本章易混淆知识点

### 1. 速率、带宽与吞吐量

- 速率：数据传输的速度。
- 带宽：网络的传输能力或信号频率范围。
- 吞吐量：实际传输的数据量速率。

### 2. 发送时延与传播时延

- 发送时延：取决于数据长度和发送速率。
- 传播时延：取决于链路长度和信号传播速率。

### 3. 电路交换与分组交换

- 电路交换：建立专用连接。
- 分组交换：将数据分成多个分组进行存储转发。

### 4. MAC 地址与 IP 地址

- MAC 地址：主要用于数据链路层的链路寻址。
- IP 地址：用于网络层的逻辑寻址。
