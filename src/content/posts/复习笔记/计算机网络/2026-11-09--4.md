## 一、网络层的基本概念

网络层是计算机网络体系结构中的第三层，位于运输层和数据链路层之间。

主要任务是实现不同网络之间的数据传输，使数据能够从源主机经过多个路由器到达目的主机。

网络层的主要功能：

1. 提供逻辑寻址。
2. 实现路由选择。
3. 实现分组转发。
4. 处理网络拥塞等相关问题。

### 1. 网络层的两个重要功能

**路由选择（Routing）**

根据目的 IP 地址选择数据传输路径。

**分组转发（Forwarding）**

路由器根据转发表，将收到的 IP 数据报从合适的接口发送出去。

两者区别：

- 路由选择：决定走哪条路。
- 分组转发：根据已经确定的转发信息实际转发数据。

## 二、IPv4 地址

### 1. IP 地址的作用

IP 地址是网络层使用的逻辑地址，用于标识网络中的主机或网络接口。

IPv4 地址长度为 32 bit，即 4 Byte。

通常采用点分十进制表示。

例如：

192.168.1.100

由四个 8 bit 的部分组成，每部分取值范围为 0～255。

### 2. IPv4 地址的组成

传统 IPv4 地址由两部分组成：

- 网络号：标识主机所属的网络。
- 主机号：标识网络中的具体主机。

具体划分取决于网络前缀长度。

### 3. IPv4 地址分类

传统分类编址分为 A、B、C、D、E 五类。


| 类别 | 地址范围（首字节） | 默认网络位数 |
| --- | --------- | ------ |
| A 类 | 1～126 | 8 bit |
| B 类 | 128～191 | 16 bit |
| C 类 | 192～223 | 24 bit |
| D 类 | 224～239 | 多播 |
| E 类 | 240～255 | 保留 |


注意：

- 127.0.0.0/8 用于环回地址。
- 0.0.0.0 有特殊用途。
- D 类地址用于多播，不用于普通主机单播地址。

### 4. 特殊 IP 地址


| 地址 | 含义 |
| --------------------- | ------------- |
| 127.0.0.1 | 常见环回地址 |
| 255.255.255.255 | 受限广播地址 |
| 0.0.0.0 | 特殊地址，常表示未指定地址 |
| 192.168.x.x | 常见私有地址范围 |
| 10.x.x.x | 私有地址范围 |
| 172.16.x.x～172.31.x.x | 私有地址范围 |


私有 IPv4 地址不能直接作为全球互联网中的公网单播地址使用。

## 三、子网划分

### 1. 为什么需要子网划分？

为了提高 IP 地址的管理效率，可以将一个较大的网络划分为多个较小的子网。

子网划分通过借用主机号中的部分位作为子网号实现。

### 2. 子网掩码

子网掩码用于区分 IP 地址中的网络部分和主机部分。

特点：

- 网络位用 1 表示。
- 主机位用 0 表示。

例如：

IP 地址：

192.168.1.100

子网掩码：

255.255.255.0

对应前缀：

/24

表示前 24 位为网络前缀，后 8 位为主机部分。

### 3. 子网划分的计算

假设：

192.168.1.0/24

现在需要划分为 4 个子网。

第一步：确定需要借用多少位。

子网数量公式：

2^n ≥ 所需子网数量

因为：

2² = 4

所以需要借用 2 bit。

第二步：计算新的前缀长度。

原前缀为 /24。

借用 2 bit 后：

/24 + 2 = /26

第三步：计算每个子网的地址数量。

主机位数：

32 - 26 = 6 bit

每个子网地址数量：

2⁶ = 64

传统 IPv4 子网中，通常有 64 个地址，其中网络地址和广播地址不能分配给普通主机，因此可用主机地址数量为：

64 - 2 = 62

第四步：确定子网范围。


| 子网 | 网络地址 | 可用主机地址 | 广播地址 |
| --- | ------------- | --------- | ---- |
| 1 | 192.168.1.0 | .1～.62 | .63 |
| 2 | 192.168.1.64 | .65～.126 | .127 |
| 3 | 192.168.1.128 | .129～.190 | .191 |
| 4 | 192.168.1.192 | .193～.254 | .255 |


子网掩码：

255.255.255.192

### 4. 常用子网掩码


| 前缀 | 子网掩码 | 地址总数 | 传统可用主机数 |
| --- | --------------- | ---- | ------- |
| /24 | 255.255.255.0 | 256 | 254 |
| /25 | 255.255.255.128 | 128 | 126 |
| /26 | 255.255.255.192 | 64 | 62 |
| /27 | 255.255.255.224 | 32 | 30 |
| /28 | 255.255.255.240 | 16 | 14 |
| /29 | 255.255.255.248 | 8 | 6 |
| /30 | 255.255.255.252 | 4 | 2 |


注意：上述可用主机数按传统普通 IPv4 子网计算，特殊用途场景可能有例外。

## 四、CIDR 无分类编址

CIDR 全称：

Classless Inter-Domain Routing

中文：无分类域间路由选择。

### 1. 为什么需要 CIDR？

传统 A、B、C 类地址存在地址分配不够灵活的问题。

CIDR 不再按照固定类别划分网络，而是使用网络前缀长度表示网络部分。

例如：

192.168.1.0/24

其中：

- 192.168.1.0 是网络地址。
- /24 表示网络前缀占 24 bit。

### 2. CIDR 的主要作用

- 提高 IP 地址分配效率。
- 支持灵活划分网络。
- 支持路由聚合。
- 缩小路由表规模。

### 3. 路由聚合

将多个连续的网络地址合并成一个更大的网络前缀。

例如：

192.168.0.0/24

192.168.1.0/24

可以聚合为：

192.168.0.0/23

前提是网络地址连续并且符合二进制前缀对齐要求。

### 4. 最长前缀匹配

路由器转发 IP 数据报时，如果有多个路由表条目都能匹配目的 IP 地址，通常选择网络前缀最长的那一项。

例如：

- 192.168.0.0/16
- 192.168.1.0/24

目的地址：

192.168.1.100

应该选择 /24，因为它的匹配前缀更长、更具体。

## 五、IP 数据报

IP 数据报由首部和数据部分组成。

### 1. IPv4 首部的主要字段


| 字段 | 作用 |
| -------- | ------------- |
| 版本 | 标识 IP 版本 |
| 首部长度 | 标识 IP 首部长度 |
| 总长度 | IP 数据报总长度 |
| 标识 | 用于分片重组 |
| 标志 | 与分片有关 |
| 片偏移 | 标识分片位置 |
| 生存时间 TTL | 限制数据报经过的路由器数量 |
| 协议 | 标识上层协议 |
| 首部检验和 | 检查首部差错 |
| 源地址 | 发送方 IP |
| 目的地址 | 接收方 IP |


### 2. TTL 的作用

TTL（Time To Live）用于限制 IP 数据报在网络中的生存时间。

每经过一个路由器，TTL 通常减 1。

当 TTL 减少到 0 时，路由器会丢弃该数据报，并通常发送 ICMP 超时报文。

主要作用：避免 IP 数据报在网络中无限循环。

### 3. IP 分片

当 IP 数据报长度超过链路所能承载的最大传输单元 MTU 时，可能需要进行分片。

IPv4 首部中的相关字段：

- 标识
- 标志
- 片偏移

用于支持分片与重组。

注意：IPv4 分片通常由目的主机完成重组，而不是由中间路由器完成重组。

## 六、ARP 协议

ARP 全称：

Address Resolution Protocol

中文：地址解析协议。

主要作用：

根据已知的 IPv4 地址，获取目标设备在当前局域网中的 MAC 地址。

### ARP 工作过程

假设主机 A 想要向同一局域网中的主机 B 发送数据。

1. 主机 A 检查本地 ARP 缓存。
2. 如果没有目标 MAC 地址，则发送 ARP 请求。
3. ARP 请求以广播方式发送。
4. 主机 B 收到请求后，发送 ARP 响应。
5. 主机 A 获得主机 B 的 MAC 地址。
6. 将对应关系保存到 ARP 缓存中。

### 重点理解

ARP 解决的是：

已知 IP 地址，如何获得对应的 MAC 地址。

如果目标主机不在同一个局域网中，发送端通常需要获取默认网关的 MAC 地址，将数据帧交给路由器转发，而不是直接获取远端主机的 MAC 地址。

## 七、ICMP 协议

ICMP 全称：

Internet Control Message Protocol

中文：网际控制报文协议。

主要作用：

用于在 IP 网络中传递控制和差错报告信息。

常见应用：

### 1. Ping

Ping 通常利用 ICMP 回送请求和回送应答报文，测试目标设备是否能够通过 IP 网络响应。

### 2. Traceroute

Traceroute 通过逐步调整探测报文的 TTL 等机制，观察沿途路由器返回的信息，以探测到目标的路径。

### 3. ICMP 常见报文

- 终点不可达
- 时间超过
- 参数问题
- 回送请求
- 回送应答

## 八、路由选择协议

路由器需要根据路由表确定数据报的下一跳和转发接口。

路由选择协议负责帮助路由器学习和维护路由信息。

### 1. 静态路由

由网络管理员手动配置路由信息。

特点：

- 配置简单。
- 不会自动适应网络变化。
- 适用于规模较小或结构稳定的网络。

### 2. 动态路由

路由器通过路由协议自动学习和更新路由信息。

常见协议：

#### RIP

Routing Information Protocol

特点：

- 使用距离向量算法。
- 主要根据跳数衡量路由距离。
- 最大有效跳数为 15。
- 16 跳表示不可达。

#### OSPF

Open Shortest Path First

特点：

- 使用链路状态路由算法。
- 通过链路状态信息建立网络拓扑。
- 使用 Dijkstra 最短路径算法计算路由。
- 适合较大规模的网络。

### RIP 与 OSPF 对比


| 比较项目 | RIP | OSPF |
| ---- | -------- | --------- |
| 算法 | 距离向量 | 链路状态 |
| 路由依据 | 跳数 | 路径代价 |
| 网络规模 | 相对较小 | 可用于较大规模网络 |
| 更新方式 | 定期交换路由信息 | 传播链路状态信息 |


## 九、NAT 网络地址转换

NAT 全称：

Network Address Translation

中文：网络地址转换。

主要作用：

将内部网络使用的私有 IP 地址转换为可用于公网通信的地址。

### NAT 工作过程

假设：

内网主机：

192.168.1.100

公网 NAT 地址：

203.0.113.10

当内网主机访问互联网时，NAT 设备会将数据包的源地址转换为公网地址。

外部服务器响应后，NAT 设备再根据转换记录，将数据返回对应的内网主机。

### PAT 端口地址转换

PAT 通过不同的端口号区分多个内部连接，使多个内网设备可以共享一个公网 IPv4 地址。

常见家庭路由器通常使用类似的机制实现多设备共享公网出口。

## 十、本章易混淆知识点

### 1. IP 地址与 MAC 地址

- IP 地址：网络层逻辑地址。
- MAC 地址：数据链路层地址。

### 2. ARP 与 DNS

- ARP：根据 IPv4 地址获取局域网中下一跳的 MAC 地址。
- DNS：将域名解析为 IP 地址。

### 3. 路由选择与分组转发

- 路由选择：确定路径。
- 分组转发：实际转发数据。

### 4. RIP 与 OSPF

- RIP：距离向量算法。
- OSPF：链路状态算法。

### 5. 子网划分与路由聚合

- 子网划分：将较大的网络分成多个较小的网络。
- 路由聚合：将多个连续网络合并成更短的网络前缀。
