# 08｜无线网络

## 一、无线网络的基本概念

无线网络是利用无线电波、红外线等无线传输介质实现设备之间通信的计算机网络。

与传统有线网络相比，无线网络不需要通过物理电缆连接所有通信设备。

常见无线网络应用：

- 手机连接 Wi-Fi。
- 笔记本电脑无线联网。
- 蓝牙耳机连接手机。
- 智能家居设备通信。
- 手机通过 4G、5G 接入互联网。

## 二、无线网络的主要特点

### 1. 优点

- 灵活性高：设备可以在覆盖范围内移动。
- 部署方便：减少布线工作。
- 扩展性较好：新增设备通常不需要重新铺设线路。
- 使用方便：适合移动设备接入。

### 2. 缺点

- 无线信号容易受到干扰。
- 传输环境变化可能影响通信质量。
- 无线信号存在被监听的风险。
- 网络覆盖范围和传输速率受到环境及技术限制。

## 三、无线局域网 WLAN

WLAN 全称：

Wireless Local Area Network

中文：无线局域网。

主要用于在局部区域内实现无线设备之间的通信。

例如：

- 家庭 Wi-Fi。
- 学校无线网络。
- 办公室无线网络。

### 1. IEEE 802.11

IEEE 802.11 是无线局域网的重要标准系列。

我们日常使用的 Wi-Fi 技术主要建立在 IEEE 802.11 标准体系之上。

常见版本：


| 标准 | 常见名称 |
| ------------- | ------------------ |
| IEEE 802.11b | 早期 Wi-Fi 标准 |
| IEEE 802.11a | 早期 Wi-Fi 标准 |
| IEEE 802.11g | Wi-Fi 早期标准 |
| IEEE 802.11n | Wi-Fi 4 |
| IEEE 802.11ac | Wi-Fi 5 |
| IEEE 802.11ax | Wi-Fi 6 / Wi-Fi 6E |


### 2. WLAN 的两种工作方式

#### 有固定基础设施的 WLAN

通常通过无线接入点 AP 实现设备接入。

基本组成：

- 无线站点。
- 无线接入点 AP。
- 分布式系统。

例如：

手机通过 Wi-Fi 连接家庭路由器，再通过路由器访问互联网。

#### 无固定基础设施的 WLAN

也称自组织网络。

设备之间可以直接建立无线通信，不依赖固定的无线接入点。

适用于临时组建的无线网络。

### 3. 基本服务集 BSS

BSS 全称：

Basic Service Set

中文：基本服务集。

它是 IEEE 802.11 无线局域网中的基本组成单元。

在基础设施模式下，一个 BSS 通常包括一个 AP 和若干无线站点。

### 4. 扩展服务集 ESS

ESS 全称：

Extended Service Set

中文：扩展服务集。

多个基本服务集可以通过分布式系统连接起来，形成扩展服务集。

例如：

学校不同楼层的多个 AP 可以组成一个较大的无线网络，使用户在覆盖区域内移动时能够继续接入网络。

## 四、无线局域网的介质访问控制

无线网络中的设备共享无线传输介质，因此需要使用介质访问控制机制。

### 1. CSMA/CA

CSMA/CA 全称：

Carrier Sense Multiple Access with Collision Avoidance

中文：载波监听多点接入 / 碰撞避免。

它是 IEEE 802.11 无线局域网中的重要介质访问控制机制。

### 2. CSMA/CA 的基本思想

1. 设备发送前先监听无线信道。
2. 如果信道忙，则等待。
3. 如果信道空闲，则按照规定等待和退避。
4. 设备获得发送机会后发送数据。
5. 接收端可以返回 ACK 确认帧。

### 3. 为什么无线局域网采用 CSMA/CA？

无线环境中，发送设备通常难以像传统共享式有线以太网那样，在发送过程中可靠地检测碰撞。

因此 IEEE 802.11 主要采用碰撞避免机制，尽量减少碰撞发生的概率。

### 4. CSMA/CD 与 CSMA/CA 对比


| 比较项目 | CSMA/CD | CSMA/CA |
| ---- | -------- | ------- |
| 中文名称 | 碰撞检测 | 碰撞避免 |
| 典型应用 | 传统共享式以太网 | 无线局域网 |
| 主要思想 | 检测碰撞 | 尽量避免碰撞 |
| 使用环境 | 传统共享有线介质 | 无线共享介质 |


注意：CSMA/CD 主要对应传统共享式半双工以太网，不应直接套用到现代全双工交换式以太网。

## 五、无线个人区域网 WPAN

WPAN 全称：

Wireless Personal Area Network

中文：无线个人区域网。

主要用于个人设备之间的短距离无线通信。

常见应用：

- 蓝牙耳机。
- 无线键盘。
- 无线鼠标。
- 智能手环。
- 智能家居传感器。

### 1. 蓝牙 Bluetooth

蓝牙是一种常见的短距离无线通信技术。

主要特点：

- 低功耗。
- 近距离通信。
- 适合个人设备互联。
- 支持多种设备之间的数据交换。

### 2. WPAN 的应用

WPAN 主要解决个人周围设备之间的通信需求。

例如：

手机通过蓝牙连接耳机，耳机与手机之间进行音频数据传输。

## 六、无线城域网 WMAN

WMAN 全称：

Wireless Metropolitan Area Network

中文：无线城域网。

主要用于覆盖城市范围的无线通信。

它的覆盖范围通常大于无线局域网。

历史上常见的相关技术包括 IEEE 802.16（WiMAX）。

## 七、蜂窝移动通信

蜂窝移动通信是一种广域无线通信技术。

通过将较大的覆盖区域划分为多个小区，实现移动设备与通信网络之间的连接。

### 1. 蜂窝结构

蜂窝移动通信网络将覆盖区域划分为多个小区，每个小区通常由基站提供无线接入服务。

主要组成：

- 移动终端。
- 基站。
- 核心网络。
- 其他网络设施。

### 2. 基站的作用

基站负责移动终端与移动通信网络之间的无线通信。

例如：

手机通过附近的基站接入运营商网络。

### 3. 蜂窝移动通信的特点

- 覆盖范围广。
- 支持移动通信。
- 可以实现用户移动过程中的网络切换。
- 通过多个小区提高频谱资源利用率。

### 4. 移动性管理

当用户从一个小区移动到另一个小区时，网络需要根据情况完成切换。

这个过程称为切换（Handover）。

主要目的是尽量保证用户在移动过程中通信不中断。

## 八、移动通信技术的发展

### 1. 第一代移动通信 1G

主要采用模拟通信技术。

特点：

- 以语音通信为主。
- 数据通信能力有限。

### 2. 第二代移动通信 2G

主要采用数字通信技术。

代表技术：

- GSM
- CDMA

特点：

- 语音通信数字化。
- 支持短信。
- 数据通信能力逐步增强。

### 3. 第三代移动通信 3G

代表技术：

- WCDMA
- CDMA2000
- TD-SCDMA

特点：

- 提高移动数据通信能力。
- 支持移动互联网应用。

### 4. 第四代移动通信 4G

代表技术：

- LTE

特点：

- 高速移动数据通信。
- 支持高清视频和移动互联网应用。

### 5. 第五代移动通信 5G

主要特点：

- 更高的数据传输速率。
- 更低的通信时延。
- 更大的网络连接能力。
- 支持物联网、工业互联网等应用。

## 九、常见无线网络技术对比


| 网络类型 | 覆盖范围 | 典型技术或应用 |
| ---- | ---- | ------- |
| WPAN | 个人周围 | 蓝牙 |
| WLAN | 局部区域 | Wi-Fi |
| WMAN | 城市范围 | WiMAX |
| WWAN | 广域范围 | 蜂窝移动通信 |


## 十、本章易混淆知识点

### 1. WLAN 与 WPAN

- WLAN：局部区域无线网络，例如 Wi-Fi。
- WPAN：个人设备之间的短距离无线通信，例如蓝牙。

### 2. CSMA/CD 与 CSMA/CA

- CSMA/CD：碰撞检测，传统共享式以太网。
- CSMA/CA：碰撞避免，无线局域网。

### 3. AP 与基站

- AP：主要用于无线局域网接入。
- 基站：主要用于蜂窝移动通信网络接入。

### 4. BSS 与 ESS

- BSS：基本服务集。
- ESS：由多个基本服务集组成的扩展服务集。
