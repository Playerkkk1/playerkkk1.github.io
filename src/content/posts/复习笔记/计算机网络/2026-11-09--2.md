## 一、物理层的基本概念

物理层是计算机网络体系结构的最底层。

主要任务：在各种传输媒体上实现比特流的透明传输。

物理层不关心具体传输的数据内容，只关心如何将 0 和 1 转换成能够在通信介质上传输的信号。

### 物理层主要解决的问题

1. 机械特性：接口形状、尺寸、引脚数量等。
2. 电气特性：规定电压范围、信号电平等。
3. 功能特性：规定接口各条信号线的作用。
4. 过程特性：规定不同功能的操作过程和时序关系。

## 二、数据通信系统

一个数据通信系统主要由三个部分组成：


| 组成部分 | 作用 |
| ---- | ------- |
| 源系统 | 产生和发送数据 |
| 传输系统 | 传输数据 |
| 目的系统 | 接收数据 |


### 1. 源系统

包括：

- 源点：产生要发送的数据。
- 发送器：将数据转换成适合传输的信号。

### 2. 目的系统

包括：

- 接收器：接收并转换信号。
- 终点：接收最终的数据。

### 3. 常见通信方式

按照通信双方的信息交互方向，可以分为：


| 通信方式 | 特点 |
| ------ | -------------- |
| 单向通信 | 只能单方向传输 |
| 双向交替通信 | 双方都能发送，但不能同时发送 |
| 双向同时通信 | 双方可以同时发送和接收 |


## 三、信号与信道

### 1. 信号

信号是数据在传输过程中的表现形式。

常见分类：

- 模拟信号：连续变化的信号。
- 数字信号：离散取值的信号。

例如：

声音经过麦克风转换后可以形成模拟信号；计算机中的 0 和 1 属于数字信息。

### 2. 信道

信道是信号传输的通道。

常见传输介质：

- 双绞线
- 同轴电缆
- 光纤
- 无线电波

### 3. 基带信号与宽带信号

基带信号：来自信源的原始信号。

带通信号：将基带信号经过调制后形成适合在特定频带中传输的信号。

## 四、码元与比特率

这是物理层计算题的重要基础。

### 1. 码元

码元是数字信号在一定时间间隔内的基本信号单位。

一个码元可以表示一个或多个比特。

例如：

- 只有两种状态：一个码元可以表示 1 bit。
- 有四种状态：一个码元可以表示 2 bit。
- 有八种状态：一个码元可以表示 3 bit。

### 2. 码元传输速率

又称波特率，表示每秒传输多少个码元。

单位：Baud（波特）。

### 3. 信息传输速率

又称比特率，表示每秒传输多少比特。

单位：bit/s。

### 4. 两者之间的关系

设：

- Rb：比特率。
- Rs：码元传输速率。
- M：码元可能的状态数量。

则：

每个码元携带的比特数为：

log₂M

比特率计算公式：

Rb = Rs × log₂M

例如：

某系统每秒传输 1000 个码元，每个码元有 4 种可能状态。

则：

log₂4 = 2 bit

Rb = 1000 × 2 = 2000 bit/s

因此比特率为 2000 bit/s。

## 五、奈奎斯特定理

奈奎斯特定理主要研究理想低通信道的最高码元传输速率。

公式：

最大码元传输速率 = 2W Baud

其中：

- W：信道带宽，单位 Hz。

若信号有 V 种离散电平，则最大数据传输速率为：

Rmax = 2W × log₂V bit/s

### 例题

某理想低通信道的带宽为 3000 Hz，采用 4 种离散电平。

求最大数据传输速率。

解：

Rmax = 2 × 3000 × log₂4

= 6000 × 2

= 12000 bit/s

答案：12000 bit/s。

### 重点记忆

奈奎斯特定理主要考虑：

- 信道带宽。
- 信号的离散电平数量。

它不考虑噪声对传输速率的限制。

## 六、香农公式

香农公式研究有噪声信道的最大信息传输速率。

公式：

C = W × log₂(1 + S/N)

其中：

- C：信道最大信息传输速率，单位 bit/s。
- W：信道带宽，单位 Hz。
- S：信号功率。
- N：噪声功率。
- S/N：信噪比。

注意：代入公式的信噪比必须是线性值，而不是直接使用 dB 数值。

### 信噪比换算

信噪比（dB）计算：

SNR(dB) = 10 × log₁₀(S/N)

因此：

S/N = 10^(SNR(dB)/10)

### 例题

某信道带宽为 3000 Hz，信噪比为 30 dB。

求信道最大信息传输速率。

第一步：将信噪比转换为线性值。

S/N = 10^(30/10)

= 1000

第二步：代入香农公式。

C = 3000 × log₂(1 + 1000)

≈ 3000 × 9.97

≈ 29910 bit/s

答案：约 29.91 kbit/s。

### 重点记忆

香农公式主要考虑：

- 信道带宽。
- 信号功率。
- 噪声功率。

信噪比越高，信道的理论最大传输速率越高。

## 七、奈奎斯特定理与香农公式的区别


| 比较项目 | 奈奎斯特定理 | 香农公式 |
| ---- | ---------- | --------------- |
| 信道条件 | 理想无噪声 | 有噪声 |
| 主要参数 | 带宽、离散电平数 | 带宽、信噪比 |
| 研究对象 | 最高码元及数据速率 | 最大信息传输速率 |
| 公式 | 2W × log₂V | W × log₂(1+S/N) |


注意：

奈奎斯特定理与香农公式描述的是不同限制条件下的理论传输能力，不能简单认为二者可以随意互换。

## 八、信道复用技术

信道复用的目的是提高通信线路的利用率，让多个用户共享同一条物理信道。

### 1. 频分复用 FDM

将不同用户分配到不同频率范围。

特点：各用户可以同时通信。

### 2. 时分复用 TDM

将通信时间划分为不同时间片，各用户轮流使用信道。

特点：不同用户在不同时间片传输数据。

### 3. 波分复用 WDM

主要用于光纤通信。

通过不同波长的光信号实现多路复用。

### 4. 码分复用 CDM

不同用户使用不同编码，通过编码区分各自的数据。

### 四种复用方式对比


| 方式 | 区分依据 | 典型应用 |
| --- | ---- | ------ |
| FDM | 频率 | 传统广播通信 |
| TDM | 时间 | 数字通信 |
| WDM | 波长 | 光纤通信 |
| CDM | 编码 | 扩频通信 |


## 九、物理层常见易错点

### 1. 比特率与波特率

比特率表示每秒传输多少比特。

波特率表示每秒传输多少码元。

两者不一定相等。

### 2. 奈奎斯特与香农

奈奎斯特主要考虑理想信道的带宽与信号电平数。

香农主要考虑有噪声信道的带宽与信噪比。

### 3. 信噪比单位

如果题目给出 30 dB，不能直接将 30 代入香农公式。

必须先转换成线性信噪比。

### 4. 单位换算

1 Byte = 8 bit。

计算时必须统一单位，特别注意：

- Hz
- kHz
- bit/s
- kbit/s
- Mbit/s
