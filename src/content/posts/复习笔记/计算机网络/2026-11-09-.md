## 一、学习资料与复习依据

- 教材：《计算机网络（第8版）》
- 作者：谢希仁
- 出版社：电子工业出版社
- 课程：湖北工程学院《计算机网络》
- 复习主线：TCP/IP 体系结构

本次复习主要参考湖北工程学院公开课程大纲，以教材九个章节为基础建立知识框架。

**注意：公开课程大纲不等于本学期最终考试范围，具体考点仍需结合任课教师实际教学内容确认。**

## 二、教材九章知识结构

### 第1章 计算机网络概述

核心内容：

- 互联网的组成与发展
- 计算机网络的定义与分类
- 电路交换、报文交换、分组交换
- 计算机网络的性能指标
- OSI 七层参考模型
- TCP/IP 体系结构
- 数据封装与解封装

重点理解：

1. OSI 七层模型与 TCP/IP 模型的区别。
2. 各层的主要功能和代表协议。
3. 分组交换的基本工作过程。
4. 计算机网络常见性能指标。

### 第2章 物理层

核心内容：

- 物理层的基本概念
- 数据通信系统
- 信道、信号与码元
- 信道容量与传输速率
- 奈奎斯特定理
- 香农公式
- 信道复用技术

重点理解：

1. 比特率与码元传输速率。
2. 奈奎斯特定理与香农公式的区别。
3. 频分、时分、波分、码分复用。

重点练习：数据传输速率及信道容量计算。

### 第3章 数据链路层

核心内容：

- 数据链路层的基本功能
- 封装成帧
- 差错检测
- 循环冗余检验（CRC）
- PPP 协议
- 以太网
- MAC 地址
- CSMA/CD
- 交换式以太网

重点理解：

1. 数据链路层如何实现透明传输。
2. CRC 的基本计算过程。
3. MAC 地址与 IP 地址的区别。
4. 以太网的工作原理。

重点练习：CRC 校验计算。

### 第4章 网络层

核心内容：

- 网络层的功能
- IPv4 地址
- IP 数据报格式
- 子网划分
- 子网掩码
- CIDR 与超网
- ARP 协议
- ICMP 协议
- 路由选择
- RIP、OSPF
- NAT 网络地址转换

重点理解：

1. IP 地址的网络号与主机号。
2. 子网掩码的作用。
3. 子网划分和 CIDR。
4. 路由表与路由选择过程。
5. ARP、ICMP 的功能。
6. NAT 的基本工作原理。

重点练习：

- IP 地址分类。
- 子网掩码计算。
- 网络地址与广播地址计算。
- 子网数量与可用主机数量计算。
- 路由选择分析。

### 第5章 运输层

核心内容：

- 运输层的功能
- 端口与套接字
- UDP 协议
- TCP 协议
- 可靠传输
- 停止等待协议
- 连续 ARQ 协议
- 滑动窗口
- 流量控制
- 拥塞控制
- TCP 连接管理

重点理解：

1. TCP 与 UDP 的区别。
2. TCP 如何实现可靠传输。
3. 滑动窗口的工作原理。
4. 流量控制与拥塞控制的区别。
5. TCP 三次握手与四次挥手。
6. TCP 序号与确认号。

重点练习：TCP 通信过程、滑动窗口及序号确认号分析。

### 第6章 应用层

核心内容：

- 域名系统 DNS
- 文件传输协议 FTP
- 远程终端协议
- 电子邮件系统
- SMTP、POP3
- 万维网 WWW
- HTTP 协议
- 动态主机配置协议 DHCP
- 网络管理协议 SNMP

重点理解：

1. DNS 域名解析过程。
2. HTTP 请求与响应过程。
3. FTP 的基本功能。
4. 电子邮件的发送与接收过程。
5. DHCP 的作用。
6. 常见应用层协议及端口号。

### 第7章 网络安全

核心内容：

- 网络安全的基本概念
- 对称加密
- 公钥密码体制
- 数字签名
- 鉴别
- 防火墙

重点理解：

1. 对称加密与非对称加密的区别。
2. 公钥与私钥的基本用途。
3. 数字签名的作用。
4. 防火墙的基本功能。

### 第8章 无线网络

核心内容：

- 无线局域网 WLAN
- 无线个人区域网 WPAN
- 无线城域网
- 蜂窝移动通信
- 无线网络的基本特点

重点理解：

1. 无线局域网的基本概念。
2. 无线网络与有线网络的区别。
3. 无线通信的基本特点。

### 第9章 下一代互联网

核心内容：

- IPv6
- IPv6 地址表示
- IPv6 数据报
- IPv4 与 IPv6 的区别
- 多协议标签交换 MPLS
- P2P 网络

重点理解：

1. IPv6 出现的原因。
2. IPv6 与 IPv4 的主要区别。
3. IPv6 地址的基本表示方法。
4. P2P 网络的基本概念。

## 四、个人复习优先级

### 第一阶段：核心协议与网络原理

优先学习：

- 第3章 数据链路层
- 第4章 网络层
- 第5章 运输层
- 第6章 应用层

### 第二阶段：基础知识与计算题

学习：

- 第1章 计算机网络概述
- 第2章 物理层

重点解决网络模型、传输速率和 CRC 等问题。

### 第三阶段：拓展知识与综合复习

学习：

- 第7章 网络安全
- 第8章 无线网络
- 第9章 下一代互联网

整理概念、协议特点与知识对比。

## 五、复习过程中的重点记录

每学习一章，按照以下结构整理：

1. 本章知识框架
2. 核心概念及定义
3. 重点协议及工作原理
4. 重要计算公式
5. 易混淆知识点
6. 典型例题与解题过程
7. 章节自测与错题复盘

## 六、阶段性学习目标

最终希望能够做到：

- 理解 TCP/IP 各层的基本功能。
- 能够区分常见网络协议及其作用。
- 能够独立完成基础网络计算题。
- 能够解释 TCP、UDP、IP 等协议的工作过程。
- 能够根据网络拓扑分析基本通信过程。
- 能够独立完成教材重点知识的复习与总结。
