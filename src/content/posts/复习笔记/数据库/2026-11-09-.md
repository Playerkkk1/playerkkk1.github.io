## 一、关系模型的完整性规则

关系模型主要包含三种完整性规则。

### 1. 实体完整性

关系中的主属性不能取空值（NULL）。

例如：学生表 S 中，学号 sno 是主键，不能为 NULL。

### 2. 参照完整性

外键的值可以为空；如果不为空，则其引用的对象必须存在。

例如：选课表 SC 中的 sno 引用学生表 S 的 sno。如果选课表中出现一个不存在于学生表的学号，就违反参照完整性。

### 3. 用户定义完整性

除实体完整性和参照完整性以外，根据实际应用需求设置的数据约束。

例如：学生成绩 grade 必须在 0～100 之间。

**记忆：**

- 实体完整性：主键不能空。
- 参照完整性：外键引用必须有效。
- 用户定义完整性：符合业务规则。

## 二、关系代数基础运算

关系代数是数据库查询的理论基础，主要通过选择、投影、并、交、差、笛卡尔积、连接和除法等操作完成数据查询。

### 1. 选择运算 σ

选择运算用于筛选满足指定条件的元组，相当于 SQL 中的 WHERE。

例如：查询张林老师所授课程。

```
σ teacher='张林' (C)
```

SQL：

```
SELECT *
FROM C
WHERE teacher = '张林';
```

### 2. 投影运算 π

投影运算用于选择需要输出的属性列，相当于 SQL 中的 SELECT 字段列表。

例如：只查询课程号和课程名。

```
π cno,cname (C)
```

SQL：

```
SELECT cno, cname
FROM C;
```

注意：关系代数的投影会去除重复元组。

### 3. 并、交、差运算

假设：

R(X,Y)：


| X | Y |
| --- | --- |
| a | d |
| b | a |
| c | c |


S(X,Y)：


| X | Y |
| --- | --- |
| d | a |
| b | a |
| d | c |


**并运算 R ∪ S**

将两个关系的元组合并，相同元组只保留一次。

```
R ∪ S
= {(a,d),(b,a),(c,c),(d,a),(d,c)}
```

SQL：

```
SELECT X,Y FROM R
UNION
SELECT X,Y FROM S;
```

**交运算 R ∩ S**

取两个关系中共同存在的元组。

```
R ∩ S = {(b,a)}
```

SQL：

```
SELECT X,Y FROM R
INTERSECT
SELECT X,Y FROM S;
```

**差运算 R - S**

保留 R 中存在、但 S 中不存在的元组。

```
R - S = {(a,d),(c,c)}
```

SQL：

```
SELECT X,Y FROM R
EXCEPT
SELECT X,Y FROM S;
```

反过来：

```
SELECT X,Y FROM S
EXCEPT
SELECT X,Y FROM R;
```

得到 S - R：

```
{(d,a),(d,c)}
```

**注意事项：**

1. UNION 自动去重，UNION ALL 不去重。
2. 差运算具有方向性，R-S 不一定等于 S-R。
3. 集合运算要求两个查询的列数相同，对应列的数据类型兼容。
4. MySQL 8.0.31 及以上支持 INTERSECT 和 EXCEPT。

### 4. 笛卡尔积 R × S

笛卡尔积是将 R 中的每一行与 S 中的每一行进行组合。

如果 R 有 m 行，S 有 n 行，则：

```
结果行数 = m × n
```

例如，R 有 3 行，S 有 3 行：

```
R × S = 3 × 3 = 9 行
```

如果 R 有 2 列，S 有 2 列，则结果有 4 列。

SQL：

```
SELECT *
FROM R
CROSS JOIN S;
```

笛卡尔积是理解连接运算的重要基础。

## 三、连接运算

### 1. 等值连接

按照指定属性相等的条件连接两个关系。

例如：

```
S ⋈ S.sno=SC.sno SC
```

SQL：

```
SELECT *
FROM S
INNER JOIN SC
ON S.sno = SC.sno;
```

等值连接会保留参与连接的重复属性列。

### 2. 自然连接

自然连接是一种特殊的等值连接。

它会自动寻找两个关系中的同名属性，要求所有同名属性同时相等，并去除重复的同名属性列。

关系代数：

```
S ⋈ SC
```

SQL：

```
SELECT *
FROM S
NATURAL JOIN SC;
```

**两者区别：**


| 比较 | 等值连接 | 自然连接 |
| ----- | ------ | -------- |
| 连接条件 | 指定相等条件 | 所有同名属性相等 |
| 条件指定 | 需要指定 | 自动判断 |
| 重复属性列 | 保留 | 去除 |


实际开发中通常优先使用明确的 JOIN ... ON，避免新增同名字段意外改变自然连接条件。

### 3. 左、右、全外连接

外连接不仅保留匹配成功的记录，还会保留指定一侧或两侧未匹配的记录。


| 关系代数 | SQL | 含义 |
| ----- | --------------- | -------- |
| R ⋈ S | INNER JOIN | 只保留匹配记录 |
| R ⟕ S | LEFT JOIN | 保留左表全部记录 |
| R ⟖ S | RIGHT JOIN | 保留右表全部记录 |
| R ⟗ S | FULL OUTER JOIN | 保留两表全部记录 |


左外连接：

```
SELECT *
FROM S
LEFT JOIN SC
ON S.sno = SC.sno;
```

右外连接：

```
SELECT *
FROM S
RIGHT JOIN SC
ON S.sno = SC.sno;
```

全外连接：

```
SELECT *
FROM S
FULL OUTER JOIN SC
ON S.sno = SC.sno;
```

**重点：**

- 匹配成功：合并记录。
- 匹配失败：未匹配的一侧属性填充 NULL。
- 一条记录可以匹配多条记录，因此外连接的结果行数不一定等于左表或右表行数。

MySQL 不直接支持 FULL OUTER JOIN，可以使用 LEFT JOIN 与 RIGHT JOIN 通过 UNION 等方式实现。

## 四、关系代数查询综合应用

数据库作业1使用了以下三个关系：

```
S(sno, sname, sex, age)

C(cno, cname, teacher)

SC(sno, cno, grade)
```

### 1. 查询张林老师所授课程的课程号和课程名

```
π cno,cname (σ teacher='张林' (C))
```

SQL：

```
SELECT cno, cname
FROM C
WHERE teacher = '张林';
```

### 2. 查询选修 C 语言或者数据库课程的学生学号

```
π sno (
    σ cname='C语言' OR cname='数据库'
    (C ⋈ SC)
)
```

SQL：

```
SELECT DISTINCT SC.sno
FROM SC
JOIN C ON SC.cno = C.cno
WHERE C.cname IN ('C语言', '数据库');
```

### 3. 查询高灵同学所选课程的课程号和课程名

```
π cno,cname (
    σ sname='高灵'
    (S ⋈ SC ⋈ C)
)
```

SQL：

```
SELECT C.cno, C.cname
FROM S
JOIN SC ON S.sno = SC.sno
JOIN C ON SC.cno = C.cno
WHERE S.sname = '高灵';
```

### 4. 查询至少选修两门不同课程的学生学号

关系代数使用重命名和自连接：

```
SC1 = ρ SC1(sno1,cno1,grade1)(SC)

SC2 = ρ SC2(sno2,cno2,grade2)(SC)

π sno1 (
    σ sno1=sno2 AND cno1≠cno2
    (SC1 × SC2)
)
```

SQL 中可以使用：

```
SELECT sno, COUNT(*) AS course_count
FROM SC
GROUP BY sno
HAVING COUNT(*) >= 2;
```

两种方法的区别：

- 关系代数：通过两条不同选课记录进行比较。
- SQL：通过 GROUP BY 分组统计选课数量。

### 5. 关系代数除法

作业1中有两道除法题。

**查询全部学生都选修的课程号及课程名：**

```
π cno,cname (
    C ⋈ (
        π cno,sno(SC) ÷ π sno(S)
    )
)
```

**查询至少选修张林老师所授全部课程的学生姓名：**

```
π sname (
    S ⋈ (
        π sno,cno(SC)
        ÷
        π cno(σ teacher='张林'(C))
    )
)
```

除法的核心含义：

寻找某个对象，使其满足另一个集合中的全部条件。

SQL 中可以使用双重 NOT EXISTS 实现这种逻辑。本次先掌握关系代数除法，双重 NOT EXISTS 留待后续专项复习。

## 五、SQL 基础操作

作业2使用的主要关系模式：

```
s(sno, sname, ssex, sbirthin, placeofb, scode, class)

c(cno, cname, classh)

sc(sno, cno, grade)

ss(scode, ssname)

t(tno, tname, tsex, tbirthin, title, tresction, tel)

teach(tno, cno)
```

### 1. CREATE TABLE 创建表

创建选课表 SC：

```
CREATE TABLE sc (
    sno VARCHAR(10),
    cno VARCHAR(10),
    grade INT,
    PRIMARY KEY (sno, cno),
    FOREIGN KEY (sno) REFERENCES s(sno),
    FOREIGN KEY (cno) REFERENCES c(cno)
);
```

这里使用联合主键：

```
PRIMARY KEY (sno, cno)
```

表示 sno 和 cno 共同确定一条选课记录。

### 2. INSERT 插入数据

插入学号 0001 的学生选修课程 1001 的记录，不设置成绩：

```
INSERT INTO sc (sno, cno)
VALUES ('0001', '1001');
```

不指定 grade，允许 NULL 时会自动使用 NULL。

### 3. DELETE 删除数据

删除没有设置成绩的选课记录：

```
DELETE FROM sc
WHERE grade IS NULL;
```

删除由 002 号教师授课且成绩不及格的选课记录：

```
DELETE FROM sc
WHERE grade < 60
AND cno IN (
    SELECT cno
    FROM teach
    WHERE tno = '002'
);
```

注意：判断 NULL 必须使用 IS NULL 或 IS NOT NULL，不能使用 = NULL。

### 4. UPDATE 更新数据

将课程号 1001 的课程学时增加 8：

```
UPDATE c
SET classh = classh + 8
WHERE cno = '1001';
```

将张三老师授课且已经设置成绩的选课记录增加 5 分：

```
UPDATE sc
SET grade = grade + 5
WHERE cno IN (
    SELECT cno
    FROM teach
    WHERE tno IN (
        SELECT tno
        FROM t
        WHERE tname = '张三'
    )
)
AND grade IS NOT NULL;
```

## 六、SQL 查询与条件筛选

### 1. WHERE 条件查询

查询 201002 班的男生：

```
SELECT *
FROM s
WHERE ssex = '男'
AND class = '201002';
```

查询所有女生，按班级降序排列：

```
SELECT *
FROM s
WHERE ssex = '女'
ORDER BY class DESC;
```

查询来自南京或上海的学生学号和姓名：

```
SELECT sno, sname
FROM s
WHERE placeofb IN ('南京', '上海');
```

### 2. JOIN 多表连接查询

查询选修课程号 C401001 的学生学号、姓名和成绩：

```
SELECT s.sno, s.sname, sc.grade
FROM s
JOIN sc ON s.sno = sc.sno
WHERE sc.cno = 'C401001'
ORDER BY sc.grade DESC, s.sno ASC;
```

查询选修数据结构课程的学生姓名及专业代码：

```
SELECT s.sname, s.scode
FROM s
JOIN sc ON s.sno = sc.sno
JOIN c ON sc.cno = c.cno
WHERE c.cname = '数据结构';
```

多表连接的基本思路：

1. 确定需要查询的字段。
2. 判断这些字段分别属于哪张表。
3. 根据主外键关系连接表。
4. 使用 WHERE 筛选符合条件的数据。

## 七、GROUP BY、聚合函数与 HAVING

分组统计是作业2的重要内容。

常见聚合函数：


| 函数 | 作用 |
| ------- | ---- |
| COUNT() | 统计数量 |
| SUM() | 求和 |
| AVG() | 求平均值 |
| MAX() | 求最大值 |
| MIN() | 求最小值 |


### 1. 查询至少选修两门课程的学生

```
SELECT sno, COUNT(*)
FROM sc
GROUP BY sno
HAVING COUNT(*) >= 2;
```

### 2. 查询最低分大于70、最高分小于90的学生姓名

```
SELECT s.sname
FROM s
JOIN sc ON s.sno = sc.sno
GROUP BY s.sname, s.sno
HAVING MAX(sc.grade) < 90
AND MIN(sc.grade) > 70;
```

### 3. 查询课程号以3开头、至少有5条选课记录的课程号和平均成绩

```
SELECT cno, AVG(grade)
FROM sc
WHERE cno LIKE '3%'
GROUP BY cno
HAVING COUNT(*) >= 5;
```

### 4. 查询同时选修001和002两门课程的学生

```
SELECT s.sno, s.sname
FROM s
JOIN sc ON s.sno = sc.sno
WHERE sc.cno IN ('001', '002')
GROUP BY s.sno, s.sname
HAVING COUNT(DISTINCT sc.cno) >= 2;
```

### WHERE 与 HAVING 的区别


| 比较 | WHERE | HAVING |
| ---------- | ------ | ------ |
| 执行阶段 | 分组前筛选 | 分组后筛选 |
| 主要作用 | 筛选原始记录 | 筛选分组结果 |
| 是否直接用于聚合条件 | 通常不可以 | 可以 |


**记忆：WHERE 先筛选，GROUP BY 再分组，HAVING 最后筛选分组。**

## 八、视图 VIEW

作业2最后一题：建立信息系（IS）所有不及格学生的视图。

```
CREATE VIEW Is_Failed AS
SELECT s.sno, s.sname, sc.cno, sc.grade
FROM s
JOIN ss ON ss.scode = s.scode
JOIN sc ON s.sno = sc.sno
WHERE ss.ssname = 'IS'
AND sc.grade < 60;
```

视图可以理解为一个基于查询定义的虚拟表。

本题执行过程：

1. 学生表 s 和专业表 ss 通过 scode 连接。
2. 学生表 s 和选课表 sc 通过 sno 连接。
3. 筛选专业名称为 IS 的学生。
4. 筛选成绩小于 60 的记录。
5. 将查询结果定义为视图 Is_Failed。
