> 核心原则：阅读理解考查的是语义是否一致，而不是单词是否相同。

## 1. 核心概念

### 1.1 同义替换（Paraphrase）

使用不同的单词、短语或句式，表达与原文相同或基本相同的意思。

**例：**

原文：The policy has a significant impact on students.

选项：The policy has a considerable impact on students.

- significant = considerable（显著的）
- 核心意思没有改变。

### 1.2 偷换概念（Distortion）

选项保留原文的部分词汇，但改变了关键含义。

**例：**

原文：a catastrophic scenario（灾难性的情景）

选项：a catastrophic mistake（灾难性的错误）

- catastrophic 相同
- scenario ≠ mistake
- 原文描述一种严重局面，选项却变成了严重错误。

**结论：原词复现不代表答案正确。**

---

## 2. 常见同义替换类型


| 类型 | 示例 |
| ----- | ----------------------------------------------------------- |
| 近义词替换 | significant → considerable |
| 短语替换 | because of → due to |
| 句式改写 | People believe that → It is believed that |
| 语义概括 | cannot afford housing → housing is financially inaccessible |


注意：同义替换必须结合上下文判断，不能认为两个词在所有语境下都可以互换。

---

## 3. 常见干扰项类型


| 类型 | 原文 → 干扰选项 |
| ----- | -------------------------------------------- |
| 偷换核心词 | catastrophic scenario → catastrophic mistake |
| 扩大范围 | some → all |
| 改变语气 | may → must |
| 频率绝对化 | often → always |
| 混淆因果 | A causes B → B causes A |
| 无依据推断 | 描述事实 → 擅自增加建议 |


### 判断方法

1. 核心名词是否发生变化？
2. 主语、动作或因果关系是否改变？
3. 范围和语气是否被扩大？
4. 选项是否增加了原文没有的信息？

## 4. 真题错题复盘

### 2024年6月六级第一套

**第52题：题干理解错误**

题干中的 *solution to* 表示解决方案，而不是问题或缺点。

错误原因：没有准确理解提问方向，就开始定位原文。

**第53题：例证目的理解困难**

题干中的 *make a point with ... as an example* 表示通过举例说明某个观点。

错误原因：不熟悉题干表达，同时存在对原文含义的过度推断。

**经验：先理解题目问什么，再判断原文说什么。**

---

## 5. 仔细阅读做题检查清单

- 读懂题干，明确提问方向
- 定位原文中的相关信息
- 判断原文的核心意思
- 寻找选项中的同义替换
- 检查是否存在偷换概念、扩大范围或过度推断
- 选择有原文依据且语义一致的选项

## 一句话总结

**正确答案重在语义一致，干扰选项常利用表面相似制造误导。**
