## 4.变量

### 4.1变量的定义格式

**数据类型 变量名 =数据值；**

### 4.2变量的使用方式

- 输出打印

```java
int a=10;
System.out.println(a);//10
```



- **参与计算**

```java
int a=10;
int b=10;
System.out.println(a+b);//20
```



- **修改记录的值**

```java
int a=10;
System.out.println(a);//10
a=20;
System.out.println(a);//20
```

> **变量的注意事项：**
>
> 1. 只能存一个值  
> 2. 变量名不允许重复定义
> 3. 一条语句可以定义多个变量
> 4. 变量在使用之前一定要进行赋值
> 5. 变量的作用域范围

## 5.计算机的存储规则

**在计算机中,任意数据都是以**二进制**的形式来存储的**

### 5.1进制

十进制: 逢十进一 借一当十

**二进制: 逢二进一  借一当二**

#### 5.1.1常见的进制

- 二进制:由0和1组成, 代码中以****0b****开头

- 十进制:由0~9组成, 前面不加任何前缀

- 八进制:由0~7组成,代码中以****0****开头

- 十六进制:由0~9还有a~f组成,代码中以****0x****开头

#### 5.1.2 进制的转换

1. **任意进制转十进制**

   **系数* 基数的权次幂 相加**

**系数:**就是每一位上的数

**权:**从右往左.依次为 0 1 2 3 4..

## 7.标识符

**含义: 就是给**类, 方法,变量**等起的名字**

### 7.1标识符命名规则

**硬性规则**

- 由数字,字母,下划线,和**美元符$**组成
- 不能以数字开头
- 不能是关键字
- 区分大小写

**软性规则:**

- 小驼峰命名法(方法,变量):
  - 标识符是一个单词,全部小写—-name
  - 标识符是多个单词,第一个单词全部小写,其他单词首字母大写—–firstName
- 大驼峰命名法(类名):
  - 标识符一个单词.首字母大写—–Student
  - 标识符是多个单词,每个单词首字母大写——GoodStudent

> 标识符应**见面知意!**

## 8.Scanner键盘录入

**介绍:**

**Java帮我们写好了一个类叫Scanner,这个类就可以接收键盘输入的数字**

- 步骤一:导包—- Scanner这个类在哪

```java
import java.util.Scanner; //导包的动作必须出现在类定义的上边
```



- 步骤二:创建对象—- 表示我们要开始用Scanner这个类了

```java
Scanner sc = new Scanner(System.in); 
//sc是变量名,可以变,其他的不允许
```



- 步骤三:接收数据—– 真正开始干活了

```java
int i = sc.nextInt();//i是变量名,可变,其他的不可变

  
int num = sc.nextInt();

System.out.println("个位:" + (num % 10));
System.out.println("十位:" + (num / 10 % 10));
System.out.println("百位:" + (num / 100));
```

> **第一套体系:**
>
> nextInt( );接收整数
>
> nextDouble( );接收小数
>
> next( );接收字符串
>
> **遇到空格,制表符,回车就停止接收,这些符号后面的数据就不会接收了**
>
> **第二体系:**
>
> nextLine( );接收字符串
>
> **可以接收空格,制表符,遇到回车才停止接收数据**
>
> **键盘录入的两套 体系不能混用的**
